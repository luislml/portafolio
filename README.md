# Luis Alfredo Soto R. | Portfolio V2.0 🚀

Bienvenido a mi portafolio profesional. Este proyecto es una vitrina de mis habilidades como **Ingeniero de Sistemas**, enfocado en el desarrollo **Frontend** y **Backend** con tecnologías modernas.

## 🛠️ Stack Tecnológico
- **Frontend**: Vite + React + Tailwind CSS
- **Animaciones**: Framer Motion + MagicUI
- **Iconografía**: Lucide React
- **Arquitectura**: Component-Based Architecture

## ✨ Características Premium
- **Diseño Responsive**: Optimizado para dispositivos móviles con un header inteligente y menú hamburguesa.
- **Efectos de Borde Dinámicos**: Implementación personalizada de `MagicCard` con bordes nítidos y haz de luz giratorio en todas las secciones clave.
- **UX Refinada**: Scroll suave, barra de desplazamiento personalizada y modo oscuro inmersivo.
- **Formulario de Contacto**: Integrado con Web3Forms para comunicación directa.
- **Estética de Terminal**: Un toque futurista y profesional que destaca entre los portafolios convencionales.

## 📁 Estructura del Proyecto
- `src/components/`: Componentes reutilizables de UI.
- `src/sections/`: Secciones principales del portafolio (Hero, About, Projects, Contact).
- `src/assets/`: Imágenes y recursos visuales.
- `src/lib/`: Utilidades y configuraciones de diseño.

## 🚀 Instalación y Uso

1. Clonar el repositorio:
   ```bash
   git clone https://github.com/tu-usuario/tu-repositorio.git
   ```
2. Instalar dependencias:
   ```bash
   npm install
   ```
3. Ejecutar en modo desarrollo:
   ```bash
   npm run dev
   ```
